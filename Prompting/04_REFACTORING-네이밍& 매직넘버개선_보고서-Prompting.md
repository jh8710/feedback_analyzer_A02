# 04_REFACTORING-네이밍& 매직넘버개선 보고서 - Prompting

## 1. 목적

이 문서는 이번 세션에서 사용한 사용자 요청과 작업 프롬프트 흐름을 기록한다.

작업 목표:

- `Constants.java`와 `TextAnalyzer.java`의 매직넘버 및 하드코딩 문자열 개선
- 의미가 모호한 변수명과 메서드명을 도메인 용어로 변경
- 변경된 메서드명에 맞춰 호출부와 테스트 갱신
- `mvn test` 기준 리팩터링 후 회귀 여부 확인
- 작업 내용과 프롬프트를 보고서 산출물로 보관

## 2. 사용자 요청 프롬프트

### 2.1 리팩터링 요청

```text
@Constants.java @TextAnalyzer.java 매직넘버를 상수로 추출하고, 의미없는 변수명을 도메인 용어로 개선해줘.
```

의도:

- `Constants.java`와 `TextAnalyzer.java`를 중심으로 네이밍과 상수 관리를 개선
- 분석 로직의 기능은 유지하면서 코드 가독성과 유지보수성 향상
- 하드코딩된 감성/카테고리 문자열과 초기 카운트 값을 명시적 상수로 이동

### 2.2 보고서 및 프롬프트 기록 요청

```text
이번세션에서 진행한 내용을 report 폴더의 04_REFACTORING-네이밍& 매직넘버개선_보고서 파일로 내보내주고, 
프롬프트를 포함해서 Prompting 폴더의 04_REFACTORING-네이밍& 매직넘버개선_보고서-Prompting.md 파일로 내보내줘
```

의도:

- 이번 리팩터링 세션의 작업 내용을 보고서로 남김
- 사용자 프롬프트와 작업 흐름을 별도 Prompting 문서로 보관
- `report`와 `Prompting` 폴더에 04번 산출물 생성

## 3. 코드 확인 단계 프롬프트 구조

리팩터링 전 다음 관점으로 코드베이스를 확인했다.

```text
Inspect Constants.java and TextAnalyzer.java first.

Read:
- src/main/java/com/example/demo/Constants.java
- src/main/java/com/example/demo/TextAnalyzer.java

Check:
1. Where sentiment and category labels are hardcoded.
2. Whether numeric literals are used as meaningful analysis values.
3. Which variable names are abbreviated or unclear.
4. Whether method names such as sent() and kw() are used elsewhere.
5. Which call sites and tests must be updated if public method names change.
```

확인 결과:

- `Constants.java`는 `"긍정"`, `"부정"`, `"배송"`, `"품질"`, `"가격"`, `"서비스"`, `"사용성"` 등을 직접 문자열로 사용하고 있었다.
- 카테고리 키워드 맵의 구조 키인 `"main"`, `"sub"`도 문자열 리터럴로 반복되고 있었다.
- `TextAnalyzer.java`는 분석 카운트 초기값 `0`을 직접 사용하고 있었다.
- `TextAnalyzer.java`에는 `sent`, `kw`, `res`, `res2`, `txt`, `cat`, `kws`, `s` 등 의미가 불명확한 이름이 있었다.
- `sent()`와 `kw()`는 `FeedbackController.java`와 `DemoApplicationTests.java`에서 호출되고 있었다.

## 4. 구현 프롬프트 구조

수정 단계에서는 다음 기준을 적용했다.

```text
Refactor naming and constants with behavior preserved.

For Constants.java:
- Extract sentiment labels into public constants.
- Extract category names into public constants.
- Extract category map keys such as main/sub into public constants.
- Extract analysis initial count 0 into a named constant.
- Rename temporary subcategory map variables to domain-oriented names.

For TextAnalyzer.java:
- Rename sent() to analyzeSentiments().
- Rename kw() to analyzeCategoryKeywords().
- Replace hardcoded sentiment labels and map keys with Constants values.
- Rename unclear local variables to domain terms.
- Keep analysis precedence and result shape unchanged.

For callers and tests:
- Update FeedbackController call sites.
- Update DemoApplicationTests call sites.
- Run tests to confirm behavior is unchanged.
```

적용 원칙:

- 기능 변경 없이 리팩터링만 수행
- 기존 테스트 기대값 유지
- 도메인 용어가 코드에 직접 드러나도록 이름 변경
- 요청 범위 밖의 구조 개편은 수행하지 않음
